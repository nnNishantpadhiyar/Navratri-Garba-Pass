# Navratri Garba Pass Ahmedabad 2026 🪔

A premium, modern, high-converting Navratri Garba Pass booking web platform designed specifically for Ahmedabad, Gujarat for Navratri 2026.

## 🌟 Key Features

- **Royal Gujarati Festive Aesthetic**: Designed with Deep Purple, Royal Indigo, Electric Crimson, Flame Orange, and Gold accents with glowing Dandiya & Mandala pattern overlays.
- **Full SEO Architecture**: Dynamic JSON-LD structured data (`Event`, `BreadcrumbList`, `FAQPage`, `Organization`), SEO-friendly clean URLs (`/garba-pass-sg-highway`, `/events/mirchi-rock-dhol-ahmedabad-2026`), canonical tags, and OpenGraph metadata.
- **Interactive Multi-Filter Discovery**: Live event search by keyword, venue, zone (*SG Highway, Bopal, Satellite, Prahlad Nagar, Thaltej, Gota, Gandhinagar, Vadodara, Surat*), price range, pass tier, and dynamic badges (*Trending, Early Bird, Limited Passes, Almost Sold Out*).
- **6-Step Ticket Checkout**:
  1. Date Picker (Oct 11 - Oct 19, 2026)
  2. Pass Tier Selector (Daily Pass, Couple Pass, 9-Night Season Pass, VIP Lounge Pass)
  3. Pass Quantity & Add-ons (VIP Valet Parking, Gujarati Dandiya Sticks Pair)
  4. Contact Information & Promo Code (`GARBA2026` for 10% Off)
  5. Payment Gateway Simulation (UPI QR Code, Credit/Debit Card, Netbanking)
  6. Digital QR Ticket Generation (`GB-2026-XXXX`) with WhatsApp sharing & print features.
- **Organizers Admin Dashboard (`/admin`)**: Total revenue, pass inventory control, bookings ledger, and gate QR entry scanner validation tool.

## 🚀 Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom CSS Utilities
- **Icons & Graphics**: Lucide React Icons, HTML5 Canvas QR Generator, Canvas Confetti

## 🛠️ Installation & Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
